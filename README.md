# Dashboard ยอดขายร้านอาหาร — บ้านโฮม

Dashboard แบบ interactive ที่ดึงข้อมูลสดจาก Google Sheet (ไฟล์ที่ Export จากโปรแกรมขาย POS)
มาแสดงเฉพาะยอดขายฝั่ง **ร้านอาหาร** โดยตัดยอดฝั่ง **รีสอร์ท/ห้องพัก** ออกให้อัตโนมัติ

เป็นเว็บ static ล้วนๆ (HTML/CSS/JavaScript ไฟล์เดียว) ไม่ต้องมี server/database ของตัวเอง
เหมาะกับการโฮสต์ฟรีบน **GitHub Pages**

## เปิดดูยังไง

1. เปิดไฟล์ `index.html` ได้เลย (ดับเบิลคลิกเปิดจากเครื่องก็ได้ หรือจะ deploy ขึ้น GitHub Pages ตามขั้นตอนด้านล่างก็ได้) — แนะนำให้ deploy ขึ้น GitHub Pages เพื่อให้มีลิงก์ส่งต่อให้คนอื่นดูได้ด้วย
2. หน้าเว็บจะดึงข้อมูลสดจาก Google Sheet ที่ตั้งค่าไว้ทันที ไม่ต้อง login หรือกรอกอะไรเพิ่ม
3. กดปุ่ม **"โหลดข้อมูลใหม่"** เมื่อไหร่ก็ได้เพื่อดึงข้อมูลล่าสุดจากชีต (auto-refresh ให้เองทุก 10 นาทีอยู่แล้ว)

## นำขึ้น GitHub Pages (ฟรี ไม่มีค่าใช้จ่าย)

1. สร้าง repository ใหม่บน GitHub (public หรือ private ก็ได้ แต่ตัว repo ต้องเป็น public ถ้าจะใช้ GitHub Pages แบบฟรี) เช่นชื่อ `bh-restaurant-dashboard`
2. อัปโหลดไฟล์ `index.html` และ `app.js` ขึ้นไปที่ root ของ repo (ลากไฟล์วางในหน้าเว็บ GitHub ก็ได้ ไม่ต้องใช้ command line)
3. เข้าไปที่ **Settings → Pages**
4. หัวข้อ **Build and deployment → Source** เลือก **Deploy from a branch**
5. เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
6. รอ 1-2 นาที แล้วเข้าลิงก์ที่ GitHub Pages ให้มา (รูปแบบ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`)

จากนี้ทุกครั้งที่มีคนเปิดลิงก์นี้ Dashboard จะดึงยอดขายล่าสุดจาก Google Sheet ให้เองอัตโนมัติ
**ไม่ต้อง deploy ใหม่เวลาข้อมูลในชีตเปลี่ยน** — แก้ที่ชีตแล้วรีเฟรชหน้าเว็บได้เลย

## ข้อกำหนดของ Google Sheet

- ต้องแชร์ชีตเป็น **"ทุกคนที่มีลิงก์ - ดูได้ (Anyone with the link – Viewer)"** ไว้ตลอด เพราะหน้าเว็บดึงข้อมูลตรงจากเบราว์เซอร์ของผู้เข้าชม ไม่ผ่าน server กลาง (ตรวจสอบแล้วว่าชีตปัจจุบันเปิดสิทธิ์นี้อยู่)
- ชื่อแท็บทั้ง 3 แท็บ (`salebyproduct`, `ยอดขายแยกตามบิล`, `ยอดขายตามสินค้ารายชั่วโมง`) และหัวคอลัมน์ ต้องคงรูปแบบเดิมตามที่ Export จากโปรแกรม POS — ถ้าเปลี่ยนชื่อแท็บหรือสลับคอลัมน์ dashboard จะดึงข้อมูลผิดหรือ error (จะมีข้อความแจ้งเตือนสีเหลืองด้านบนของหน้าเว็บถ้าตรวจพบปัญหา)
- ถ้าจะ Export ยอดขายเดือนใหม่เพิ่ม แนะนำให้ **วางข้อมูลต่อท้าย (append)** ในแท็บเดิม ไม่ต้องสร้างแท็บใหม่ทุกเดือน

## ถ้าเจอ banner สีเหลืองแจ้งปัญหาการดึงข้อมูล

Dashboard ดึงข้อมูลด้วย "ชื่อแท็บ" เป็นค่าเริ่มต้น ซึ่งปกติทำงานได้เลย แต่ถ้าเกิดปัญหา (เช่นเปลี่ยนชื่อแท็บ) ให้แก้เป็นดึงด้วยเลข **gid** แทน:

1. เปิด Google Sheet เอง ไปที่แท็บที่มีปัญหา
2. ดูเลขท้าย URL หลัง `#gid=` เช่น `...#gid=123456789`
3. เปิดไฟล์ `app.js` ด้วยโปรแกรมแก้ไขข้อความ (Notepad, VS Code ฯลฯ) หาโค้ดส่วนนี้ที่ด้านบนสุดของไฟล์:

   ```js
   TABS: {
     items:  { name: "salebyproduct",                    gid: null },
     bills:  { name: "ยอดขายแยกตามบิล",                   gid: null },
     hourly: { name: "ยอดขายตามสินค้ารายชั่วโมง",          gid: null },
   },
   ```

4. ใส่เลข gid ที่คัดลอกมาแทน `null` ของแท็บนั้น เช่น `gid: 123456789` แล้วบันทึกไฟล์ อัปโหลดทับของเดิมบน GitHub

## ปรับแต่งได้เองที่ไฟล์ `app.js` (ส่วน `CONFIG` บนสุดของไฟล์)

| ต้องการปรับ | แก้ตรงไหน |
|---|---|
| Sheet ID (ถ้าเปลี่ยนไฟล์ฐานข้อมูล) | `CONFIG.SHEET_ID` |
| หมวดสินค้าที่ถือว่าเป็นรีสอร์ท/ห้องพัก (ตัดออกจากยอดร้านอาหาร) | `CONFIG.RESORT_CATEGORIES` — ปัจจุบันตัด `"รีสอร์ท"` และ `"ห้องพัก พูลวิลล่า"` (ครอบคลุมห้องเล็ก/ห้องใหญ่/เฮือนกลางนา/เฮือนอิงน้ำ/เฮือนร่มไม้ทั้งหมด) ถ้าต้องการตัดหมวด `"ค่าห้อง VIP"` หรือ `"เคาท์เตอร์"` ออกด้วย ให้เพิ่มชื่อหมวดต่อท้ายในลิสต์นี้ |
| ช่วงเวลาแบ่งมื้ออาหาร | `CONFIG.MEAL_PERIODS` |
| ความถี่ในการดึงข้อมูลใหม่อัตโนมัติ | `CONFIG.AUTO_REFRESH_MINUTES` (ตั้งเป็น `0` เพื่อปิด) |

## วิธีคำนวณตัวเลขสำคัญ (สำคัญ ควรอ่าน)

- **ยอดขายร้านอาหาร / เมนูขายดี / หมวดสินค้า / ช่วงเวลาขายดีเฉพาะร้านอาหาร** — คำนวณจากรายงาน `salebyproduct` และ `ยอดขายตามสินค้ารายชั่วโมง` โดยกรองหมวดสินค้ารีสอร์ทออก ค่อนข้างแม่นยำเพราะมีข้อมูลระดับ "รายเมนู" ให้กรองได้ตรงๆ
- **จำนวนบิล / ยอดขายเฉลี่ยต่อบิล** — คำนวณจากรายงาน `ยอดขายแยกตามบิล` **ซึ่งรวมทั้งบิลร้านอาหารและบิลรีสอร์ท** เพราะรายงานนี้ไม่มีข้อมูลรายเมนูต่อบิลให้แยกได้ว่าบิลไหนมีแต่ค่าห้องพักล้วนๆ (ตามที่ตกลงกันไว้ตอนสร้าง dashboard) ถ้าในอนาคตโปรแกรม POS มีรายงานที่มีทั้งเลขที่บิลและรายการอาหารในบิลเดียวกัน จะสามารถแก้ให้แม่นยำขึ้นได้
- **กราฟ "ช่วงเวลาขายดี เฉพาะร้านอาหาร"** — ใช้รายงาน `ยอดขายตามสินค้ารายชั่วโมง` ซึ่งไม่มีคอลัมน์วันที่ในไฟล์ต้นฉบับ จึงเป็นยอดสะสมของ**ทั้งช่วงข้อมูลที่มีอยู่ในชีต** ไม่ตอบสนองต่อตัวกรองวันที่ด้านบนของหน้าเว็บ
- **ไม่แสดงตัวเลข "กำไร"** — ไฟล์ POS ที่ Export มายังไม่มีการบันทึกต้นทุนวัตถุดิบต่อเมนู (คอลัมน์ต้นทุนเป็น 0 ทุกแถว) ถ้าใส่ต้นทุนในระบบ POS ภายหลัง แจ้งมาได้เพื่อเพิ่มกราฟกำไร/margin ในเวอร์ชันถัดไป

## โครงสร้างไฟล์

```
index.html   หน้าเว็บหลัก (โครงสร้าง, การจัดวาง, สไตล์)
app.js       ตั้งค่า Google Sheet + ตรรกะดึง/ทำความสะอาด/สรุปข้อมูล + วาดกราฟ
README.md    ไฟล์นี้
```

ไม่มี build step ไม่ต้องรัน `npm install` ใดๆ — แก้ไฟล์แล้วอัปโหลดทับได้เลย
